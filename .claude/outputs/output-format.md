# OUTPUT FORMAT

기본적으로 모든 답변은 아래 형식을 따른다.

---

## 1. 요청 요약
- 이번 요청에서 해결할 목표 한 줄 요약

## 2. 확인 대상
- 볼 파일
- 볼 로그
- 볼 모듈

## 3. 판단
- 문제 원인 또는 개선 포인트
- 근거
- 영향 범위

## 4. 실행안
- 어떤 순서로 수정/확인할지
- 최소 변경 기준
- 검증 방법

## 5. 결과물
아래 중 필요한 형식으로 출력한다.

### A. 코드 수정안
- 변경 파일
- 수정 포인트
- 코드 블록

### B. 문서 초안
- md 파일 내용 전체 또는 수정본

### C. 운영 대응안
- 확인 명령어
- 예상 원인
- 복구 순서

### D. 리뷰 결과
- 잘된 점
- 문제점
- 추가 수정 필요 여부

---

## 응답 스타일

- 짧고 명확하게
- 불필요한 서론 금지
- 항목화 중심
- 추측 금지
- “확인 필요”와 “확정”을 구분해서 표현
