# SKILL: doc-impact

## ROLE
코드 변경 또는 구조 변경이 문서에 어떤 영향을 주는지 판단한다.

---

## INPUT
- 변경 파일 목록
- 변경 내용
- 기존 md 문서들
- 요청 목적

---

## TASK

아래를 판단한다.

1. 어떤 문서가 영향받는가
- architecture
- deployment
- project-overview
- current-task
- review-template
- 기타 README/운영문서

2. 문서 수정 수준
- 수정 불필요
- 일부 문장 수정
- 섹션 추가
- 문서 전체 갱신

3. 문서화 핵심 포인트
- 구조 변화
- 실행 방식 변화
- 운영 방식 변화
- 출력 형식 변화

---

- 실제 변경과 연결되는 문서만 언급

- 어떤 문서의 어느 성격이 바뀌는지 명확히 적을 것
