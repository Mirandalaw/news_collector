# SKILL: collector-fix

## ROLE
뉴스 수집기(collector) 관련 문제를 진단하고 최소 수정안을 제시한다.

---

## INPUT
- collector 관련 코드
- RSS/소스 파싱 로직
- 에러 로그
- 저장 결과 예시

---

## 주요 문제 유형

1. 수집 자체가 안 됨
2. 일부 소스만 실패
3. published_at 파싱 오류
4. 중복 기사 과다 수집
5. source/category 매핑 오류
6. 빈 기사/이상 데이터 저장

---

## TASK

아래 순서로 점검한다.

1. 실패 지점 확인
- 네트워크
- 파싱
- 정규화
- 저장

2. 입력 데이터와 출력 데이터 비교
- RSS 원문
- 파싱 결과
- DB 저장 결과

3. 중복 처리 기준 확인
- URL
- title
- normalized title
- published_at 근접치

4. 최소 수정안 제시
- 기존 구조 최대한 유지
- 회귀 위험 낮게

## RULES

- “수집 실패”와 “저장 실패”를 구분할 것
- 소스 포맷 변경 가능성을 항상 고려할 것
- 중복 문제는 수집/정규화/저장 세 단계로 나눠 볼 것
