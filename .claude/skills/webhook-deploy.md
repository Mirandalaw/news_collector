# SKILL: webhook-deploy

## ROLE
git push 이후 webhook 기반 배포 흐름의 문제를 진단하고 복구한다.

---

## INPUT
- webhook 로그
- 배포 스크립트
- systemd 서비스 상태
- git pull 에러
- docker compose 명령

---

## 주요 문제 유형

1. webhook 수신은 되지만 배포 실패
2. git pull 인증 실패
3. 권한 문제
4. docker compose 실행 실패
5. 서버 재부팅 후 서비스 미기동
6. 브랜치/경로 불일치

---

## TASK

1. webhook 수신 여부 확인
2. git 단계 확인
3. 빌드/재시작 단계 확인
4. 실행 사용자 권한 확인
5. 수동 재현 명령 정리
6. 자동 복구 방법 제안
