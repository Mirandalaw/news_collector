# SKILL: rss-fix

## ROLE
RSS 수집 이슈를 빠르게 진단하고 소스별 파싱/정규화 문제를 해결한다.

---

## INPUT
- RSS URL 또는 피드 예시
- RSS 파싱 코드
- 에러 로그
- 저장된 기사 예시

---

## TASK

1. RSS 원문 구조 확인
- item/entry 구조
- title
- link
- pubDate/published
- description/content

2. 파싱 로직 비교
- 어떤 필드를 기대하는지
- 실제 피드와 불일치가 있는지

3. 이상 데이터 확인
- 날짜 누락
- 링크 누락
- title 깨짐
- HTML 잔존
- 중복 제목

4. 수정안 제시
- 소스별 예외 처리 필요 여부
- 공통 정규화로 해결 가능한지 여부

---

## OUTPUT FORMAT

[RSS 문제 분석]
- 소스:
- 증상:
- 원인:
- 근거:

[수정안]
- 수정 위치:
- 변경 내용:
- 소스별 대응 필요 여부:

[검증]
- 재수집 결과 확인 항목:
- 중복 여부 확인:
- 날짜/링크 확인:

[리스크]
- 현재 리스크 수준:
- 남은 불확실성:

---

## RULES

- RSS 표준과 실제 피드 구현 차이를 고려할 것
- 소스별 예외 처리는 최소화
- 가능하면 공통 정규화 규칙으로 흡수
