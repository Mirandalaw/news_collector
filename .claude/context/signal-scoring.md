# SIGNAL SCORING

## 목적

여러 개의 signal을 종합하여
기사 단위가 아니라 종목/시장 단위의 매매 판단 점수를 만든다.

현재 시스템은 기사별 signal 생성까지는 가능하지만,
실제 매매 판단을 위해서는 여러 signal을 하나의 score로 합산하는 단계가 필요하다.

이 문서는 signal을 점수화하는 기준과
초기 매매 판단 규칙의 설계 기준을 정의한다.

---

## 현재 상태

현재 시스템은 아래 단계까지 구현되어 있다.

1. 뉴스 수집
2. dedup 및 noise filtering
3. event 분류
4. signal 생성
5. signal dedup

즉, 지금은 "좋은 기사와 signal을 생성하는 시스템" 상태이며,
다음 단계는 이를 실제 투자 판단 기준으로 연결하는 것이다.

---

## 핵심 목표

1. 여러 signal을 하나의 점수로 종합한다
2. 점수를 기준으로 매수 / 매도 / 관망 판단을 만든다
3. 초기 버전은 단순하고 설명 가능한 규칙 기반으로 유지한다
4. 뉴스만으로 확정 매매하지 않고, 후속 차트/가격 필터와 결합 가능한 구조로 만든다

---

## 점수화 원칙

signal은 importance와 direction을 기반으로 점수화한다.

### importance 가중치

- HIGH = 3
- MEDIUM = 2
- LOW = 1

### direction 반영

- BULLISH = +weight
- BEARISH = -weight
- NEUTRAL / MIXED = 0

---

## 점수 합산 방식

동일 종목 또는 시장에 대해 수집된 signal들을 합산한다.

예시:

- 실적 서프라이즈 (HIGH, BULLISH) → +3
- 지정학 리스크 (MEDIUM, BEARISH) → -2
- 유가 상승 (MEDIUM, BEARISH) → -2

최종 점수:
-1

---

## 초기 판단 기준

초기 버전은 아래 기준으로 단순하게 시작한다.

### 시장/종목 공통

- score >= +3 → 매수 후보
- score <= -3 → 매도/회피 후보
- -2 ~ +2 → 관망

이 기준은 초기 MVP용이며,
차후 백테스트 및 실전 운영 결과에 따라 조정할 수 있다.

---

## 적용 단위

초기 구현은 아래 두 단위를 고려한다.

### 1. 시장 전체 점수
시장 관련 기사(signal)를 종합하여
당일 시장 전반 방향성 점수를 계산한다.

### 2. 종목별 점수
종목 관련 signal을 종합하여
개별 종목의 뉴스 기반 점수를 계산한다.

---

## 설계 원칙

1. 규칙 기반으로 유지한다
2. 점수 계산 과정을 설명 가능하게 만든다
3. 과도한 모델링이나 복잡한 스코어링은 넣지 않는다
4. 차트/가격 필터와 결합하기 전 단계라는 점을 유지한다

---

## 금지사항

- ML 모델 도입
- 뉴스만으로 즉시 매매 실행 확정
- 복잡한 가중치 튜닝
- 동적 threshold 최적화
- 기술적 지표를 이 단계에 섞기

---

## 출력 형태

초기 스코어링 함수는 아래 정보를 반환하는 것이 바람직하다.

- total_score
- bullish_count
- bearish_count
- contributing_signals
- 판단 결과 (buy / sell / hold)
