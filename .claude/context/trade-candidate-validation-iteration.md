# TRADE CANDIDATE VALIDATION (ITERATION 2)

## 목적

price filter의 volume 조건 완화 이후,
매매 후보 품질이 실제로 개선되었는지 검증한다.

---

## 변경 사항

이전:
- volume >= avg_volume

현재:
- volume >= avg_volume * 0.7

---

## 검증 목표

1. 후보 개수 정상화 여부 확인
2. 기존 false negative 해결 여부 확인
3. false positive 신규 발생 여부 확인
4. 전체 후보 품질 유지 여부 확인

---

## 검증 기준

### 1. 후보 개수

- 이전: 0건
- 목표: 1~3건

---

### 2. false negative 개선

다음 케이스 반드시 확인:

- 삼성전자 (005930)
- NVDA

조건:
- 이전 탈락 → 현재 통과 여부

---

### 3. false positive 발생 여부

다음 확인:

- 의미 없는 종목이 후보로 포함되는지
- 약한 뉴스인데 후보로 뜨는지

---

### 4. price filter 영향

각 후보에 대해 확인:

- MA20 조건
- surge_ratio 조건
- volume 조건 (완화 후 영향)

---

## 기록 포맷

### 예시

- 날짜: 2026-04-XX
- 종목: 005930
- 이전: 탈락
- 현재: 통과
- 판정: 개선됨

또는

- 종목: XXXX
- 이전: 없음
- 현재: 후보 생성
- 판정: false positive

---

## 분석 기준

다음 질문에 답해야 한다:

1. 후보 수는 정상 범위인가?
2. 기존 문제는 해결됐는가?
3. 새로운 문제는 생겼는가?
4. 추가 수정이 필요한가?

---

## 출력 목표

반드시 하나 선택:

1. 현재 조건 유지
2. 추가 조정 필요 (1개만)

---

## 금지사항

- 추가 기능 구현
- threshold 다중 변경
- 감 기반 판단
