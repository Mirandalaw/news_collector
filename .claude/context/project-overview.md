# PROJECT OVERVIEW

프로젝트명:
뉴스 수집 및 아침 브리핑 자동화 시스템

---

## 프로젝트 목적

여러 뉴스 소스에서 기사를 수집하고,
중복과 노이즈를 줄인 뒤,
핵심 내용만 정리한 아침 브리핑을 자동 생성하는 것이 목적이다.

---

## 핵심 문제

기본 뉴스 수집만으로는 아래 문제가 발생한다.

1. 같은 내용이 여러 기사로 반복됨
2. 중요하지 않은 기사가 브리핑에 섞임
3. 카테고리 분류 품질이 일정하지 않음
4. 운영 중 cron / 배포 / 권한 문제로 실행이 끊길 수 있음

---

## 현재 시스템이 해결해야 하는 것

1. 안정적 수집
2. 중복 기사 제거
3. 브리핑 품질 개선
4. 로그 기반 운영 안정화
5. 데이터 누적에 대한 보존 정책 설계

---

## 주요 관심사

### 제품 관점
- 아침에 바로 읽을 수 있는 수준의 브리핑
- 반복 없는 요약
- 카테고리 균형
- 너무 긴 출력 방지

### 엔지니어링 관점
- 작업 단위 분리
- 재실행 가능성
- 장애 원인 추적 가능성
- 유지보수 가능한 구조

---

## 우선순위

1. 뉴스 브리핑 품질 개선
2. 중복 기사 필터링 강화
3. 운영 자동화 안정성 확보
4. 데이터베이스 보존/정리 정책 수립

---

## 작업 판단 기준

좋은 변경의 기준:
- 브리핑 품질이 올라간다
- 중복 노출이 줄어든다
- 장애 추적이 쉬워진다
- 운영 명령이 단순해진다
- 변경 범위 대비 효과가 크다
