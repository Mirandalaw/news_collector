# BRIEFING QUALITY CONTEXT

## 목표
브리핑을 단순 기사 나열이 아니라 투자 판단에 도움되는 이벤트 중심 구조로 개선한다.

---

## 기존 문제

1. 같은 이슈가 여러 언론사 기사로 반복 노출됨
2. 기사 단위 나열이라 핵심 이벤트가 잘 안 보임
3. 시장 영향 / 관련 종목 / 리스크가 빠져 있음
4. 중요 뉴스와 잡음 뉴스 구분이 약함

---

## 개선 목표

1. 기사 중심이 아니라 이벤트 중심으로 묶는다
2. 동일/유사 이슈는 하나의 이벤트로 병합한다
3. 이벤트별 중요도를 점수화한다
4. 시장 영향과 관련 종목을 함께 정리한다
5. 투자 판단에 필요한 리스크를 포함한다

---

## 브리핑 단위 정의

### article
개별 기사 단위 데이터

### event
같은 이슈를 다루는 여러 기사들의 대표 묶음

브리핑은 article이 아니라 event 단위로 출력하는 것을 목표로 한다.

---

## 좋은 브리핑 기준

1. 같은 이슈 반복이 적다
2. 이벤트별 핵심이 한 번에 보인다
3. 중요도가 구분된다
4. 시장 영향과 관련 종목이 포함된다
5. 투자 판단 시 주의할 리스크가 함께 보인다

---

## 개선 관점

브리핑 품질 문제는 아래 네 단계로 나눠서 본다.

1. 수집 문제
- 불필요한 기사 과다 수집
- source 편향

2. dedup 문제
- 완전 중복 / 준중복 제거 실패

3. event grouping 문제
- 같은 이슈가 여러 이벤트로 분리됨

4. ranking 문제
- 중요도 낮은 기사가 위에 노출됨
